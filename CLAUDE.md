# elektronik.kz — контекст для Claude Code

Интернет-магазин электроники (ТОО/ИП пользователя, направление среди нескольких параллельных бизнес-инициатив). Читай этот файл в начале любой новой сессии в этом репозитории — ниже сжатая история решений, которые не видны из одного только кода.

## Стек и статус

- **Django 6.1**, Python 3.13, SQLite для разработки.
- `config/` — настройки и urlconf проекта. `shop/` — приложение магазина (пока пустое: моделей, вьюх и шаблонов ещё нет).
- `manage.py check` и `migrate` проходят чисто. Витрины ещё нет — это голый скелет.

## Как дошли до этого стека (2026-08-24)

Проект был размазан по трём несинхронизированным местам:
1. **Этот репозиторий** — раньше содержал Laravel-скелет (2 коммита, включая случайно закоммиченную `vendor/`, 8244 файла). Полностью удалён и заменён на Django.
2. **Хостинг hoster.kz** (тот же провайдер, что у ecomeken.kz) — корень домена отдаёт 403 (заглушка с 2021 года), но по адресу `elektronik.kz/wordpress/` был рабочий демо-магазин на WordPress/WooCommerce с каталогом из 7 товаров. **Решение: отказаться от WordPress**, эта ветка больше не развивается.
3. **Google Drive**, папка `elektronik-kz` — содержит то, что в git не попало:
   - прайс-листы поставщиков (**FDCOM/Acer, Marvel**) — активно обновляются, это реальный источник товарного ассортимента, ещё не подключён к проекту;
   - файл учёта остатков;
   - старый `.env.example` с продакшн-конфигом (`APP_URL=https://elektronik.kz`, MySQL) — актуален только по домену/окружению, не по стеку (там был Laravel).

Итог: Python/Django выбран сознательно, чтобы не распыляться на два стека и не тратить время на PHP, который пользователь не использует в других проектах.
